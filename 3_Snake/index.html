NEON SNAKE

歡迎來到 Neon Snake，一個融合了現代毛玻璃（Glassmorphism）與螢光霓虹美學的極致貪食蛇遊戲。

🎮 遊戲規則

  • 使用 WASD 或 方向鍵 控制蛇的轉向。
  • 按下 空白鍵 (Space) 隨時暫停或繼續遊戲。
  • 吃下螢光粉紅色的食物以獲得分數並增長蛇身。
  • 撞到外牆或自己的身體將會結束遊戲。
  • 行動端支援螢幕滑動手勢或點擊下方的虛擬 D-Pad。
